### Silvanexum: spend control for AI agents

See what every LLM call cost, **which customer and which agent** it was for, and stop a call
before it runs when a budget is spent. Works across OpenAI, Anthropic, Gemini and NVIDIA NIM.

**Open source:** [silvanexum/Silvanexum-sdk](https://github.com/silvanexum/Silvanexum-sdk):
TypeScript and Python SDKs, an MCP server, NVIDIA NeMo plugins and a VS Code extension.
Apache-2.0, with signed npm provenance and token-free publishing.

```bash
npm i @silvanexum/sdk        # TypeScript
pip install silvanexum       # Python
npx -y @silvanexum/mcp       # MCP server for Claude, Cursor, Windsurf
```
